# ESP32-L E-Paper Development Board

Source: [good-display.com/product/338.html](https://www.good-display.com/product/338.html)

## Basic

| Parameter | Value |
|---|---|
| Part Number | 6010000 |
| Platform | Arduino |
| Primary Function | Drive E-paper Display |
| MCU | ESP32-WROOM-32D |
| Wireless | WiFi + Bluetooth |
| Power Interface | USB Type-C |
| Dimensions | 70 x 54 mm |
| Operating Temperature | -20°C ~ 70°C |

## Features

- Integrated WiFi + Bluetooth (vs ESP8266)
- Faster processor than predecessor models
- Ultra-low power consumption
- Type-C connector with LED indicator
- Reset button
- Integrated font chip
- Integrated flash chip
- Current detection

## Display Compatibility

Drives serial E-Ink displays with 24-pin interfaces, sizes from 0.97" up to 13.3", including touchscreen variants.

Supported connector variants: C02, C097, C102, C31, C579, C73, C1085.
